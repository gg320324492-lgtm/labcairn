# Registration records

**One record per copy, named for the material id.** The format is stated in
[`../README.md`](../README.md), and the records are written and checked by
[`../../../scripts/pilot_material_registration.py`](../../../scripts/pilot_material_registration.py).

**There is no record here yet.** The pilot's material has not been chosen
— that choice is the owner's (G0 §4) — and nothing is registered until a
copy is registered and the owner has signed the checklist result (D-6).
The standing candidate G0 §4 names is the natural default and nothing
more.

The folder is here so that the place a record goes is a place, and so
that the witness that checks whatever is in it is never vacuous.
